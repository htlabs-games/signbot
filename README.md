# <img src=https://odysea.us.to/assets/static/woodsignload.gif width="auto" height="32px"> SignBot

Bot for the ODYSEA Discord server. https://discord.gg/jasyA3PgPJ btw.

## Installation

Install [Python](https://python.org) at least version 3.8 or higher from the official website or using your package manager, then make sure you install the required dependencies by running the following command.

```sh
pip3 install -r requirements.txt
```
